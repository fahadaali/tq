# منصة تقييم أفكار استدامة جمعية هدية عالم

منصة استبيان تشاركية بسيطة لتقييم أفكار ورشة العمل وفق **منهجية المرحلة الثانية: المعايير الوزنية**.
واجهات عصرية بأسلوب آبل (الزجاج السائل)، عربية بالكامل (RTL)، انتقال بالتلاشي، ولوحة تحكم للأدمن مع تصدير Excel / CSV.

## المنهجية

تُقيَّم كل فكرة على **٤ معايير وزنية** بمقياس من ١ إلى ٥:

| المعيار | الوزن |
|---|---|
| و١ الجدوى المالية وحجم الإيراد | ٤٠٪ |
| و٢ كفاءة رأس المال والتكلفة | ٣٥٪ |
| و٣ سهولة وسرعة التنفيذ | ٢٠٪ |
| و٤ الأثر الرسالي والقيمة المضافة | ٥٪ |

**النتيجة = مجموع (التقييم × الوزن) × ٢٠** (نسبة من ١٠٠).

التصنيف: 🟢 ≥٩٠ عالية · 🟡 ٨٠–٨٩ متوسطة · 🟠 ٦٠–٧٩ منخفضة · 🔴 <٦٠ مستبعدة.

## التشغيل

```bash
npm install
npm start          # المنفذ الافتراضي 3000 (أو متغيّر البيئة PORT)
```

- صفحة المقيّم: `http://localhost:3000/`
- لوحة تحكم الأدمن: `http://localhost:3000/admin`

## المزايا

- **صفحة المقيّم:** تعريف بالمشروع والمنهجية، إدخال الاسم والدور، ثم فكرة واحدة لكل شاشة بمعاييرها الأربعة.
  تنقّل بالتلاشي مع أزرار تقدّم/تراجع، مخطط نقاط أسفل الصفحة للتنقّل السريع، إشارة مرجعية لكل فكرة (لون ذهبي)،
  خانة ملاحظة اختيارية لكل فكرة، وحفظ تلقائي للمسودة في المتصفح.
- **لوحة الأدمن (/admin):** داشبورد بالإحصاءات، ترتيب الأفكار حسب المتوسط مع تصنيف لوني، جدول الردود مع تفاصيل
  قابلة للتوسعة، حذف أي رد مع رسالة تأكيد، وتصدير النتائج إلى Excel أو CSV.

## البيانات

تُحفظ الردود في `data/responses.json` (غير مُتتبَّع في git). مصدر الأفكار والمعايير: `data/dataset.js`.

> ملاحظة: لوحة `/admin` غير محمية بكلمة مرور حسب الإعداد المطلوب. لإضافة حماية لاحقاً يمكن وضع المنصة خلف
> بوابة مصادقة أو إضافة تحقق على مسارات `/admin` و `/api/responses`.
